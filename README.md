# Солнечная система 3D

Интерактивная модель Солнечной системы на Godot 4.7.2 и C++ (GDExtension):
эфемериды JPL DE440/DE442 через NAIF SPICE, N-body, редактирование параметров тел, полёт от м/с до сверхсветовой скорости.

Статус: MVP готов — этапы 1–8 закончены 14.10.2026, сборка для Windows — `build\release\SolarSystem.exe`. Есть конвейер данных, ядро физики на C++ и сцена Godot:
тела из чанков кубосферы с картами NASA, USGS и Solar System Scope до 8K (подкачка по мере приближения), рельеф,
атмосфера Земли, облака и огни городов, Солнце с потемнением к краю и короной, тени колец и затмения, кольца Сатурна,
орбиты, полёт от 1 м/с до 1000 c, перелёт и облёт, интерфейс на русском; правка параметров тел с пересчётом,
отменой и повтором, предупреждениями об устойчивости и сценариями JSON; 118 тысяч звёзд Hipparcos и Млечный Путь
NASA; окно «Источники» со всеми источниками данных и лицензиями.

## Данные

Сырые файлы (ядра SPICE, SPK Horizons, страницы NASA, карты USGS и JPL, рельеф) лежат в `data/raw/` и в git не входят.
Список, MD5 и происхождение — в [docs/sources.md](docs/sources.md). Повторная загрузка: ядра NAIF — `bash tools/fetch_naif.sh`,
карты и рельеф — `python -I pipeline/fetch_maps.py`, звёзды и Млечный Путь — `python -I pipeline/fetch_stars.py`. Карты Solar System Scope копируются из справочного проекта
`D:\work\Vanya\space\godot\assets\textures` (сайт отдаёт 403 скриптам).

Файлы игры в `game/data/` собираются из `data/raw/`:

| Файл | Что внутри | Скрипт |
| --- | --- | --- |
| `ephemeris.eph` (726 МиБ, в git не входит) | полиномы Чебышёва: DE440 и DE442 (Уран, Нептун) 1550–2650, спутники и центры планет 1900–2100, малые тела 1600–2500 | `pipeline/export_eph.py` |
| `time.json` | високосные секунды и константы TDB−TT из naif0012.tls | `pipeline/timeconv.py` |
| `spice_constants.json` | GM, радиусы, модели вращения из pck00011 и gm_de440 | `pipeline/export_constants.py` |
| `bodies.json`, `sources.json` | 36 тел и 3 возмущающих, у каждого значения — источник | `pipeline/build_bodies.py` |
| `dynamics.json` | модель динамики для N-body: GM, Jₙ, поле Марса, полюса — как в спутниковых ядрах JPL | `pipeline/export_dynamics.py` |
| `appearance.json` и `game/assets/maps/` (215 МБ, в git не входят) | карты 2K и 8K в общей раскладке, карты нормалей, маска воды; источник, лицензия, доля снятой поверхности и множитель яркости каждой карты; параметры атмосферы Земли, Солнца и короны | `pipeline/build_textures.py` |
| `stars.bin` и `game/assets/sky/` (в git не входит) | звёзды Hipparcos: направление, собственное движение, V, цвет; карта Млечного Пути NASA SVS | `pipeline/build_stars.py` (исходники — `pipeline/fetch_stars.py`) |

В `bodies.json` у Сатурна есть кольца (края, оптическая толщина, альбедо) со страницы NASA Saturnian Rings Fact Sheet.

Формат `.eph` описан в начале [pipeline/eph_format.py](pipeline/eph_format.py).

## Запуск

Готовая игра — папка `build\release` (собирает `.\tools\export.ps1`): `SolarSystem.exe` (104,2 МБ),
`SolarSystem.pck` с данными и картами (1 384 МБ), `spacecore.windows.template_release.x86_64.dll` (2,0 МБ);
Папку можно копировать целиком. Требования: Windows 10/11 x64,
видеокарта с Vulkan и 6 ГБ видеопамяти.

Из исходников:

```powershell
C:\Tools\Godot\Godot_v4.7.2-stable_win64.exe --path game
```

Или открыть папку `game` в редакторе Godot 4.7.2 и нажать F5. Перед первым запуском соберите C++ и данные
(раздел «Сборка и тесты»). Открывается вид на Землю в текущий момент, время идёт 1 с/с.

Управление:

| Что | Как |
| --- | --- |
| Полёт | W/S — вперёд/назад, A/D — влево/вправо, R/F — вверх/вниз, Q/E — крен |
| Взгляд | правая кнопка мыши (или левая на пустом месте) |
| Скорость полёта | колесо мыши в полёте, клавиши [ и ], ползунок внизу: от 1 м/с до 1000 c |
| Облёт | O — облетать выбранное тело; мышь — вокруг тела; колесо — ближе/дальше (логарифмически) |
| Перелёт | G, двойной щелчок по подписи или по телу в списке: 2–5 с |
| Вращаться вместе с телом | B или флажок слева |
| Время | ползунок вверху (1 с/с — 1000 лет/с), «Пауза» (Пробел), «Назад», «Сейчас» (Home), дата UTC с Enter |
| Режим | «Эфемериды» (JPL) или «Симуляция» (N-body); за пределами 1900–2100 «Симуляция» включается сама |
| Слои и экспозиция | флажки «Атмосфера», «Облака Земли», «Огни городов», «Звёзды», «Млечный Путь» и ползунок «Экспозиция» слева (Солнце вблизи — около −13 EV, корона при затмении — около +2 EV) |
| Правка параметров | вкладка «Параметры» справа: новое значение в столбце «стало», Enter; Ctrl+Z / Ctrl+Y — отменить / повторить; «Сохранить сценарий…» / «Загрузить…» — `user://scenarios` |
| Устойчивость | вкладка «Устойчивость»: предел Роша, уход, сближения орбит, столкновения, плотность, вращение |
| Источники | кнопка «Источники и лицензии» слева: все источники данных, версии, MD5, лицензии |
| Снимок экрана | F12 → `user://screenshots` |
| Подсказка | F1 |

## Ядро (native/)

- `src/core/ephemeris.*` — чтение `.eph` (схема Кленшоу как в SPICE: совпадение до бита).
- `src/core/timeconv.*` — UTC ↔ TDB, как в SPICE.
- `src/core/orientation.*` — ориентация тел по IAU (pck00011).
- `src/core/nbody.*` — N-body: IAS15, ОТО (EIH), поля планет, иерархические координаты спутников.
- `src/core/gravity_field.*` — поле в сферических гармониках (рекурсия Каннингема).
- `src/core/catalog.*`, `json.*` — каталог тел и начальное состояние «Симуляции» (совпадает с Python до бита).
- `src/core/sim_runner.*` — «Симуляция» в потоке: снимки, интерполяция Эрмита, уровни упрощения.
- `src/core/kepler.*` — коники для линий орбит и спутники на прецессирующих элементах.
- `src/core/camera_rig.*` — камера в double: полёт с инерцией, облёт, перелёт.
- `src/core/cubesphere.*` — кубосфера с квадродеревом чанков.
- `src/godot/solar_system.*` — узел `SolarSystem`: время и режимы, floating origin, чанки, кольца, орбиты.
- `src/godot/solar_system_look.cpp` — внешний вид: карты из `appearance.json`, подкачка 8K, освещение, затмения,
  Солнце с короной, оболочка атмосферы.
- `src/godot/solar_system_edit.cpp` и `src/core/scenario.*` — правка параметров, отмена и повтор, производные величины,
  предупреждения устойчивости, сценарий JSON (этап 6).
- `src/godot/solar_system_sky.cpp` — звёзды Hipparcos и Млечный Путь (этап 7).
- `src/godot/space_core.*` — класс `SpaceCore` (эфемериды из GDScript); `src/capi/` — C-API для тестов на Python.

## Игра (game/)

- `scenes/main.tscn`, `scripts/main.gd` — сцена, ввод; `scripts/ui.gd`, `overlay.gd`, `fmt.gd` — интерфейс.
- `shaders/` — поверхность тел (`body`), Солнце (`sun`), корона (`corona`), оболочка атмосферы (`sky`) и общий
  расчёт рассеяния (`atmosphere.gdshaderinc`), звёзды (`stars`), Млечный Путь (`milkyway`), кольца, орбиты; `compress.gdshaderinc` — логарифмическое сжатие расстояний.
- `tests/scenarios.gd` — оконные тест-сценарии этапов 4–8; `export_presets.cfg` — экспорт для Windows.

## Сборка и тесты

```powershell
.\tools\build_data.ps1     # пересобрать game/data из data/raw
.\tools\build_native.ps1   # собрать C++: game/bin (GDExtension) и native/bin (тесты, C-API)
.\tools\run_tests.ps1      # тесты C++ и pytest (около 5 минут, открываются окна Godot); -Full — ещё долгие (около 25 минут)
```

```powershell
.\tools\export.ps1                  # сборка игры в build\release (C++ release, импорт, экспорт)
.\tools\run_tests.ps1 -Exported     # собрать и прогнать оконные тесты внутри SolarSystem.exe (данные из .pck)
```

Первая сборка `build_native.ps1` компилирует godot-cpp и идёт около 15 минут (для release — ещё столько же).
Внутри exe работают те же сценарии, что в редакторе: `SolarSystem.exe --fixed-fps 60 -- --scenario=<имя> --out=<папка>`
(`game/tests/scenarios.gd`); pytest берёт exe из переменной `SPACE_EXE`.
